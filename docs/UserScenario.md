# 마이링크 (MyLink) 사용자 시나리오 (User Scenario)

## 📌 문서 개요
- **목적:** 마이링크의 방문자(Visitor)와 소유자(Owner)가 서비스를 이용하는 구체적인 행동 흐름(User Flow)을 명세합니다.

## 1. 방문자 (Visitor) 시나리오
### 1.1. 마이링크 페이지 접속 및 탐색 과정
- **페이지 접속:** 방문자는 [특정 개발자(소유자)가 정리해 둔 포트폴리오, SNS, 기술 블로그 등의 통합 링크를 확인]하기 위해 [소유자에게 제공받은 마이링크 URL(`domain.com/displayName`)을 브라우저에 입력해 접속]한다.
- **아이콘 식별:** 방문자는 [어떤 성격의 페이지인지 직관적으로 빠르게 파악]하기 위해 [각 링크 버튼 좌측에 자동 렌더링된 파비콘(Favicon) 아이콘을 시각적으로 탐색]한다.
- **원하는 링크 이동:** 방문자는 [자신이 원하는 상세 작업물이나 웹페이지로 진입]하기 위해 [수많은 목록 중 해당 링크 버튼을 마우스로 클릭(또는 터치)]한다.

---

## 2. 소유자 (Owner) 시나리오
### 2.1. 링크 관리(추가/수정/삭제) 과정
- **링크 추가:** 소유자는 [방문자에게 내 새로운 웹페이지 주소를 공유]하기 위해 [하단의 `+ 링크 추가` 버튼을 누르고 새로운 URL과 연결 제목(타이틀)을 빈칸에 입력]한다.
- **링크 수정 (인라인 편집):** 소유자는 [기존에 등록한 링크의 제목이나 주소의 오타를 바로잡거나 새로운 내용으로 업데이트]하기 위해 [수정하려는 화면상의 텍스트 영역(타이틀 또는 URL)을 직접 클릭해 인라인 모드에서 텍스트를 수정]한다.
- **링크 삭제:** 소유자는 [더 이상 유효하지 않은 특정 링크를 방명록에서 아예 제거]하기 위해 [해당 링크 영역 우측 끝에 배치된 '휴지통(삭제)' 아이콘을 클릭]한다.

### 2.2. 프로필 관리 및 공유 과정 (개선 및 제안)
- **프로필 인라인 수정:** 소유자는 [자신의 이름(`username`)이나 한 줄 소개 텍스트를 최신화]하기 위해 [프로필 영역의 텍스트를 직접 클릭하여 인라인 상태로 수정]한다.
- **내 주소 공유:** 소유자는 [설정이 완료된 자신의 마이링크 전체 페이지를 지인이나 SNS에 편하게 올리]기 위해 [화면 상단에 있는 '내 링크 복사' 기능을 클릭해 클립보드에 복사]한다.
